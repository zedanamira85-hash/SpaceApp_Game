# Mission Nova | Europa Deep

Extract the ZIP, then open **index.html** in a current browser. Keep all files together. The game works offline.

1. Read the brief and select **Start Mission**.
2. Build a spacecraft and watch the telemetry. Include the ice-melting drill.
3. Select **Check & Launch** and follow E.V.A.'s advice if any check fails.
4. Choose how to investigate the ocean, then send a summary or full dataset to Earth.
5. Review the report. **Improve This Design** keeps your choices. **Reset All Selections** clears them.

Two builds to compare:

- **Light, lower cost:** Falcon Heavy, melt-in ice shielding, 5× eMMRTG, drill, sonar, and camera.
- **Greater science capacity:** SLS Block 1B, melt-in ice shielding, 5× eMMRTG, drill, submarine science payload, and sonar.

This is a fictional future mission. See **SOURCES.md** for research and game assumptions.
